# Laços de Esperança — versão com 3 páginas HTML

Estrutura mantida conforme solicitado:

- index.html
- projetos.html
- cadastro.html
- css/style.css
- js/app.js
- js/data.js
- js/templates.js
- js/validation.js
- js/storage.js

## Funcionalidades implementadas

1. Navegação entre os três HTMLs.
2. Templates JavaScript para gerar os cards de conteúdo.
3. Formulário com validação em JavaScript.
4. Máscaras para CPF, telefone e CEP.
5. Feedback de erro e sucesso.
6. Modal após cadastro válido.
7. Persistência dos cadastros no localStorage.
8. JavaScript modularizado por responsabilidade.
9. Menu responsivo.
10. Layout responsivo.

## Como executar

Use o Live Server do VS Code ou outro servidor local, pois o projeto utiliza JavaScript Modules.

Importante: a senha é validada, mas não é salva no localStorage.
